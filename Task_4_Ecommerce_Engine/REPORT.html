Secure E-Commerce Engine

Architecture, security, payment flow, and verification report · 2026

A premium boutique storefront for considered leather goods, built with React, Express, MongoDB, Mongoose, JWT authentication, bcrypt password hashing, and Stripe test mode.

Architecture

The application is split into independent client and server npm workspaces. React and Vite provide the storefront, while Express and Mongoose provide the API and persistence boundary. Models cover users, products, carts, and orders. Routes separate authentication, catalog, carts, checkout, and order history.

  • Ten-product idempotent MongoDB catalog seed
  • JWT sessions with protected cart, checkout, and order routes
  • Stripe Elements payment form with server-side PaymentIntent pricing
  • Responsive editorial UI with skeletons, empty states, toasts, and reduced-motion support

Security Decisions

  • Passwords use bcryptjs with a work factor of 12.
  • JWTs use a seven-day expiry, issuer, and current-user lookup.
  • Registration validates email and strong passwords server-side.
  • Helmet, CORS allowlisting, body-size limits, API rate limiting, and auth rate limiting are enabled.
  • Stripe secret keys remain server-only; the browser receives only a publishable-key config value.
  • Prices, stock, cart totals, and payment amounts are always recalculated on the server.

Payment Flow

  1. Authenticated checkout loads the current cart from MongoDB.
  2. The API creates a Stripe PaymentIntent for the database subtotal.
  3. Stripe Elements confirms the test payment in the browser.
  4. The API retrieves the PaymentIntent and accepts only succeeded.
  5. Stock is decremented, the order is recorded, and the cart is cleared in a Mongo transaction.

Stripe Test Cards

  • Success: 4242 4242 4242 4242
  • Generic decline: 4000 0000 0000 0002
  • 3D Secure: 4000 0025 0000 3155

Use any future expiry date, any three-digit CVC, and any valid postal code.

Verification

The automated suite covers API health and safe errors, bcrypt registration and password validation, cart total representation, database-derived payment amounts, and React rendering. The complete live payment walkthrough requires a running MongoDB instance or Atlas URI and the owner's Stripe sandbox keys.

Design System

Ivory paper, deep forest green, oxidized brass, and restrained rust accents create the boutique direction. Cormorant Garamond provides editorial personality; DM Sans keeps operational UI legible. Product imagery and generous spacing are paired with practical mobile navigation and responsive layouts at 375px, 768px, and 1440px.
